# 히트맵

**히트맵**은 한국어 뜻을 보고 영어 단어를 맞히면서 별을 모으는 초등학생용 브라우저 게임입니다. 수채화 밤숲을 배경으로, 무무 옆 모내기판에서 단어별 학습 진행을 볼 수 있습니다. PC와 스마트폰 브라우저에서 플레이할 수 있습니다.

## 게임 방법

1. 화면 상단에서 초등학교 1~6학년 중 하나를 고릅니다. 기본 단어는 학년별 100개씩, 총 600개입니다.
2. 화면에 나온 한국어 뜻에 맞는 영어 단어를 입력하고 **정답 확인**을 누릅니다. 한 판에 5문제가 나오며, 새 단어와 복습할 단어가 섞여 출제됩니다.
3. 정답이면 **다음 문제**로 넘어갑니다. 오답이면 한국어 뜻 오른쪽에 올바른 철자가 표시됩니다. 그 철자를 직접 입력하면 다음 문제로 넘어갑니다.
4. 한 판이 끝나면 맞힌 문제 수를 확인하고 **한 판 더**를 눌러 이어서 연습합니다.

같은 학년에 뜻이 같은 단어가 여러 개 있으면, 문제에 첫 글자와 글자 수를 표시해 구분합니다. 입력과 확인에는 Enter 키도 사용할 수 있습니다.

## 모내기판과 별

단어마다 모내기판에서 차지하는 칸이 정해져 있습니다. 칸을 누르면 판 왼쪽 아래에서 영어 단어와 한국어 뜻을 확인할 수 있습니다.

| 단계 | 표시 | 조건 |
| --- | --- | --- |
| 기본 | 빈 칸 | 아직 정답 기록이 없는 단어 |
| 1단계 | 세모별 | 같은 단어를 1번 맞힘 |
| 2단계 | 네모별 | 같은 단어를 2번 연속 맞힘 |
| 3단계 | 밝은 노란색 별 | 같은 단어를 3번 연속 맞힘 |

연속 정답은 단어마다 따로 기록합니다. 틀리면 그 단어의 연속 정답 기록이 다시 시작되며, 모내기판에는 이미 달성한 가장 높은 단계가 남습니다. 오답을 확인한 뒤 따라 쓴 답은 복습으로 처리합니다.

판 위에는 완성한 칸 수와 범례가 나옵니다. 스마트폰 세로 화면에서는 판 아래 왼쪽에 무무와 모양별 별 개수, 오른쪽에 문제와 입력칸이 표시됩니다. 키보드가 열리면 화면 배치를 줄여 판과 채점 안내를 함께 볼 수 있도록 조정합니다. 보이는 공간이 특히 좁을 때는 퀴즈와 입력칸이 먼저 보이도록 합니다.

## 단어 추가와 기록 저장

상단의 **단어 추가** 또는 **＋**를 눌러 학년, 영어 단어, 한국어 뜻을 입력하면 해당 학년 판에 칸이 추가됩니다. 학습 기록과 추가 단어는 현재 사이트 주소의 브라우저 저장 공간에 저장됩니다. 다른 기기나 브라우저에서 플레이하면 각자 별도의 기록을 사용합니다.

## 실행 방법

저장소를 내려받은 뒤 [heatmap/index.html](heatmap/index.html)을 브라우저로 엽니다. 웹 서버로 미리 보려면 저장소의 최상위 폴더에서 다음 명령을 실행하고 [로컬 히트맵](http://localhost:8000/heatmap/)을 엽니다.

```sh
python3 -m http.server 8000
```

게임은 HTML, CSS, JavaScript로 구성되어 별도 설치나 빌드가 필요 없습니다. GitHub Pages에 올릴 때는 저장소의 **Settings → Pages**에서 배포 소스를 `main` 브랜치의 `/(root)`로 설정하면 됩니다. 배포가 완료되면 [GitHub Pages에서 히트맵 열기](https://natchrai.github.io/game/heatmap/)로 접속할 수 있습니다.
